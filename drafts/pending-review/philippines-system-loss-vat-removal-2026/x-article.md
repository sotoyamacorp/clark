# フィリピン電気料金、12% VAT除外へ。ただしsystem loss自体は消えない

フィリピンの電気料金からsystem loss chargeがなくなる——という話ではありません。

今回の変更は、許容system loss chargeに上乗せされる12% VATを外すものです。

## 何が変わるのか

system lossは、電線や変圧器での物理的損失、盗電や計量不備などで、需要家まで届かなかった電力です。

ERCが認める上限内の料金本体は残ります。外れるのは、その料金に対するVATです。

## いつから下がるのか

ERCはResolution No. 26を承認済み。BIRは9月2日、必要な期間の経過後に確認通達を出す方針を示しました。

つまり、2026年9月3日時点では「次回請求から必ず」とはまだ言えません。通達番号、発効日、各配電事業者の反映月を確認する必要があります。

企業の概算削減額は、

system loss charge × 12%

です。総電気料金が12%下がるわけではありません。

工場、冷蔵倉庫、ホテル、データセンターなどは、通達前後の請求書を保存し、複数拠点で反映差がないか確認しておくと実務的です。
