# フィリピン輸出単価0.5%増、輸入0.3%増に鈍化

## はじめに

フィリピン統計庁（PSA）が2026年8月28日に公表したUnit Value Index（UVI、貿易単価指数）によると、**2026年4〜6月の輸出単価は前年同期比0.5%上昇、輸入単価は0.3%上昇**しました。輸出は1〜3月の1.09%増から、輸入は1.5%増から伸びが鈍化しています。

かみ砕くと、UVIは輸出入の「金額÷数量」で得た平均単価の変化です。同じ製品の値札だけを追う純粋な価格指数ではありません。高価格品と低価格品の構成が変わっても動くため、貿易額や採算を読むには数量・為替・品目構成と組み合わせる必要があります。

PSAは2026年に基準年を2018年から2023年へ変更し、商品分類も2022 Philippine Standard Commodity Classificationへ更新しました。これは近年の輸出入構成を反映するためです。2018〜2022年は新基準に合わせたバックキャスト系列が公開され、時系列比較が可能です。

機械・電気機器には半導体や電子部品など、フィリピンの主要貿易品が含まれます。ただし分類は広く、1.5%という値を自社製品へそのまま当てはめることはできません。11桁の品目分類や自社HSコードへ掘り下げる必要があります。

## 貿易額の増加と矛盾しない

PSAの月次統計では2026年7月の貿易総額は前年同月比16.3%増の222.7億ドルでした。一方、Q2のUVI上昇は輸出0.5%、輸入0.3%です。

時期は完全には一致しませんが、「単価上昇が小さいのに貿易額が増える」ことは矛盾ではありません。数量増、品目構成、高価格品の比率、為替などが貿易額を押し上げるからです。月次の金額と四半期のUVIは、同じ表で比較する前に対象期間を揃えます。

## 日本企業の実務チェック

<div class="border-l-4 border-accent-500 bg-white p-6 shadow-sm my-8"><h3 class="font-bold text-gray-900 mb-3">こういう企業にとって重要</h3><p class="text-gray-700 leading-relaxed">電子部品、機械、金属、自動車部品、商社、物流の企業に重要です。輸出単価と輸入単価が同時に緩やかに上がる局面では、販売価格だけでなく輸入部材の原価、ペソ・ドル・円の為替、運賃、在庫評価を同時に見る必要があります。</p></div>

1. 自社品のHSコードとPSAの分類を対応させる。
2. UVI、数量、貿易額を同じ期間で比較する。
3. 契約通貨ごとに円・ペソ・ドルの為替影響を分ける。
4. CIF/FOB、運賃、保険、関税を単価から切り分ける。
5. 品質・モデル構成の変化が平均単価を動かしていないか確認する。
6. 基準年変更前後の系列を混ぜず、2023年基準のバックキャストを使う。
