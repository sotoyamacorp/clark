# X Articles専用ヘッダー画像 生成指示

## サイズ・構図
- 横長 5:2 比率
- 主要要素はすべて中央の安全領域(画面中央60%程度)に配置し、左右端が切れても意味が通じるようにする
- ロゴ・透かし・読める生成文字(タイトル文字等)は一切入れない(画像内テキストなし)

## デザイン方向性
- ブランドカラー: ネイビー(濃紺、#0a1e42前後のグラデーション)を背景ベースに、ゴールド/アンバー系のアクセントカラー(#d4a944前後)を差し色として使用
- モチーフ: 世界地図または地球儀のシルエット(発光する接続線・ノードで「国際ネットワーク」を表現)と、フィリピン・クラーク周辺を示す控えめな光点やピンを1箇所配置する。世界規模のネットワークに、クラークという1点がつながっているイメージ
- 雰囲気: 国際会議・グローバルビジネスを連想させる、落ち着いた高級感のあるトーン。派手すぎる未来的CGは避け、経済誌の特集ページのような品のあるビジュアルにする
- 建物や具体的な人物の顔を大きく描写しない(実在人物の肖像を生成しない)。抽象的な地図・光の接続線・特区を思わせる建築シルエット(低層のビジネスパーク風の建物群のシルエットなど)にとどめる

## 避けるべき要素
- 文字・ロゴ・透かし・国旗の正確な描写(誤りが生じやすいため)
- 実在人物の顔の生成
- ごちゃごちゃした要素の詰め込み(主役は「世界地図/ネットワーク」+「クラークを示す1点」のシンプルな構図)
