# クラーク進出の税制優遇「CREATE MORE法」を徹底解説：CDC登録企業が受けられる恩恵と注意点

## はじめに

「フィリピンには税制優遇があるらしいが、具体的にどんな恩恵があるのか」「PEZAに登録すればいいと聞いたが、クラークも同じなのか」——クラーク進出を検討する企業から、こうした質問をよくいただきます。

結論から言うと、**クラーク・フリーポート・ゾーンの税制優遇はPEZAではなくCDC(クラーク開発公社)が所管**しており、根拠となる法律も2024年に大きく改正されています。この記事では、2024年施行の「CREATE MORE法」によって何が変わったのか、そしてクラーク進出企業が実際にどのような恩恵を受けられるのかを整理します。

## CREATE MORE法とは何か

CREATE MORE法(正式名称：Republic Act No. 12066)は、2024年11月11日にマルコス大統領が署名した法律です。フィリピンの投資誘致における税制優遇を、より国際競争力のある内容に拡充することを目的としています。実施細則(IRR)は2025年2月17日に財務省・貿易産業省によって署名されており、この署名にはクラーク開発公社(CDC)のデバナデラ総裁も立ち会っています。

### 主な改正内容

<div class="space-y-6 my-8">
  <div class="border-l-4 border-accent-500 bg-white p-6 shadow-sm">
    <h4 class="font-bold text-gray-900 mb-3">1. 優遇期間の延長</h4>
    <p class="text-gray-700 text-sm leading-relaxed">
      税制優遇を受けられる最大期間が、従来の17年から27年に延長されました。長期の設備投資を前提とする製造業にとって、投資回収計画が立てやすくなります。
    </p>
  </div>

  <div class="border-l-4 border-accent-500 bg-white p-6 shadow-sm">
    <h4 class="font-bold text-gray-900 mb-3">2. 法人税率の引き下げ</h4>
    <p class="text-gray-700 text-sm leading-relaxed">
      拡張控除方式(Enhanced Deductions Regime)を選択した登録企業の法人税率が、25%から20%に引き下げられました。
    </p>
  </div>

  <div class="border-l-4 border-accent-500 bg-white p-6 shadow-sm">
    <h4 class="font-bold text-gray-900 mb-3">3. 電力費控除の拡大</h4>
    <p class="text-gray-700 text-sm leading-relaxed">
      電力コストに対する追加控除が100%に拡大されました。製造業など電力消費の大きい業種にとって、実質的なコスト削減効果があります。
    </p>
  </div>
</div>

## クラーク進出企業が実際に受けられる恩恵

CREATE MORE法のもとで、クラーク・フリーポート・ゾーンの登録企業(Registered Business Enterprise、RBE)は主に以下の恩恵を受けられます。

<div class="grid grid-cols-1 md:grid-cols-2 gap-6 my-12">
  <div class="bg-white border-2 border-gray-200 rounded-lg p-6 shadow-sm">
    <div class="text-3xl mb-3">🏛️</div>
    <h4 class="text-base font-bold text-gray-900 mb-3">法人所得税免除(ITH)</h4>
    <p class="text-sm text-gray-700 mb-4">
      立地や業種の優先度(SIPPの区分)に応じて、4〜7年間の法人所得税が免除されます。免除期間終了後は、総所得に対する5%の特別法人税(通常の25%に代わるもの)が適用されます。
    </p>
  </div>

  <div class="bg-white border-2 border-gray-200 rounded-lg p-6 shadow-sm">
    <div class="text-3xl mb-3">📦</div>
    <h4 class="text-base font-bold text-gray-900 mb-3">資本設備の免税輸入</h4>
    <p class="text-sm text-gray-700 mb-4">
      登録事業に直接使用する資本設備について、輸入関税が免除されます。工場設備や生産ラインを新規導入する企業にとって、初期投資の負担軽減につながります。
    </p>
  </div>

  <div class="bg-white border-2 border-gray-200 rounded-lg p-6 shadow-sm">
    <div class="text-3xl mb-3">🧾</div>
    <h4 class="text-base font-bold text-gray-900 mb-3">VATゼロ税率(国内仕入)</h4>
    <p class="text-sm text-gray-700 mb-4">
      登録事業に直接使用する国内での仕入・サービスについて、VATがゼロ税率になります。ただし後述の通り、証明書の取得が条件になります。
    </p>
  </div>

  <div class="bg-white border-2 border-gray-200 rounded-lg p-6 shadow-sm">
    <div class="text-3xl mb-3">🏗️</div>
    <h4 class="text-base font-bold text-gray-900 mb-3">SIPP優先分野は優遇拡大</h4>
    <p class="text-sm text-gray-700 mb-4">
      グリーンテクノロジーなど、政府の戦略的投資優先計画(SIPP)で重点分野に指定された事業は、最大8年間のITHが認められる場合があります。
    </p>
  </div>

## 登録・運用で見落としがちな注意点

### CDCとPEZAは別組織

クラーク・フリーポート・ゾーンに進出する企業は、**PEZAではなくクラーク開発公社(CDC)**に登録します。CDCはBCDA(基地転換開発庁)傘下の投資誘致機関(IPA)であり、PEZAとは別の組織です。CREATE MORE法はPEZAだけでなくCDCなど複数のIPAに登録する企業にも適用されますが、「フィリピン進出＝PEZA登録」という一般的な情報だけを見て準備を進めると、窓口を誤ってしまう可能性があります。

### VATゼロ税率には証明書が必要

PEZAが2025年に発出した通達(Memorandum Circular No. 2025-052)では、VATゼロ税率の適用対象は「登録事業に直接必要な仕入」に限定されることが明確化されました。RBEはIPAからVATゼロ税率証明書を取得する必要があり、これがないと仕入先から12%のVATを請求される可能性があります。この点はCDC登録企業についても同様の考え方が適用されるため、契約前に確認しておくことをおすすめします。

## まとめ：進出準備のステップ

CREATE MORE法による税制優遇を正しく活用するには、以下の順序で確認を進めることをお勧めします。

  <ol class="space-y-6">
    <li class="flex gap-4">
      <span class="flex-shrink-0 w-8 h-8 bg-accent-500 rounded-full flex items-center justify-center font-bold text-sm text-navy-950">1</span>
      <div>
        <h3 class="font-bold mb-1 text-white">自社事業がSIPPの優先分野に該当するか確認する</h3>
        <p class="text-sm text-white">優先分野への該当有無で、受けられるITH期間や優遇内容が変わります</p>
      </div>
    </li>
    <li class="flex gap-4">
      <span class="flex-shrink-0 w-8 h-8 bg-accent-500 rounded-full flex items-center justify-center font-bold text-sm text-navy-950">2</span>
      <div>
        <h3 class="font-bold mb-1 text-white">CDCへの登録要件・必要書類を確認する</h3>
        <p class="text-sm text-white">PEZAとは異なる窓口であることを踏まえ、早い段階で問い合わせておきます</p>
      </div>
    </li>
    <li class="flex gap-4">
      <span class="flex-shrink-0 w-8 h-8 bg-accent-500 rounded-full flex items-center justify-center font-bold text-sm text-navy-950">3</span>
      <div>
        <h3 class="font-bold mb-1 text-white">VATゼロ税率証明書の取得プロセスを事前に把握する</h3>
        <p class="text-sm text-white">仕入先との契約前に確認しておくことで、後からの追加コストを防げます</p>
      </div>
    </li>
  </ol>
</div>

税制優遇は魅力的な制度ですが、登録先や証明書取得などの実務面を誤ると、想定していた恩恵を受けられないケースもあります。制度の詳細は変更される可能性があるため、実際の登録にあたっては専門家への確認と合わせて進めることをおすすめします。
